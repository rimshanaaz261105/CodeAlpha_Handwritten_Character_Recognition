# Handwritten Character Recognition

This project recognizes handwritten digits using a Convolutional Neural Network (CNN) trained on the MNIST dataset.

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Features
- Image classification
- CNN deep learning model
- 98%+ accuracy
- Prediction visualization

## Dataset
MNIST Handwritten Digits Dataset

## How to Run

```bash
python train_model.py
python app.py
